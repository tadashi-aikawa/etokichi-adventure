# エトキチの大冒険 — Battle Trial

初代PS版『モンスターファーム』の「間合い・ガッツ・リアルタイム判断」を軸にした、1対1バトルのプロトタイプです。

公開版: <https://tadashi-aikawa.github.io/etokichi-adventure/>

## 起動

Node.jsとpnpmが必要です。依存関係をインストールしてViteの開発サーバーを起動します。

```sh
pnpm install
pnpm dev
```

ブラウザで <http://127.0.0.1:4173/etokichi-adventure/> を開きます。本番用ファイルは `pnpm build` で `dist/` に生成できます。生成結果は `pnpm preview` を実行し、<http://127.0.0.1:4173/etokichi-adventure/> で確認できます。

## 開発時の検証

TypeScriptの型検査、Biomeのlint・format確認、Vitest、Viteの本番ビルドをまとめて実行できます。

```sh
pnpm check
```

キャラクター定義と純粋な戦闘計算は `src/game/` のTypeScriptモジュールで管理します。既存のゲーム進行コードは、挙動を保ちながら段階的にTypeScriptへ移行しています。

実装の責務分担、アセット配置、変更時の確認観点は [`docs/development.md`](docs/development.md) にまとめています。

## 描画バックエンド

アリーナ、キャラクター、技、状態変化の視覚演出はPixiJSで描画します。通常はWebGPUを優先し、初期化できない環境ではWebGLへ切り替えます。両方を初期化できない場合はゲームを開始しません。DOM/CSS製レンダラーへのフォールバックはありません。

HUD、選択画面、文字表示とPC向け操作ボタンはDOMレイヤーとしてPixiJSのキャンバスへ重ねています。スマートフォン横画面の操作レールはPixiJSで描画します。また、非表示のキャラクター画像要素とclassは、PixiJS側へ画像変更や動作状態を伝えるために使います。これらは描画バックエンドではなく、GPU版のUI・状態同期層です。

URLのクエリで検証するバックエンドを指定できます。

- `?renderer=webgpu`: WebGPUを優先し、失敗時はWebGLへ切り替え
- `?renderer=webgl`: WebGLを使用

GPU側は背景とワールド空間を別コンテナに分け、ゲーム本体からカメラ位置・ズーム・キャラクター位置を受け取ります。将来マップ移動を追加する場合も、このワールド空間へタイルやオブジェクトを追加し、同じカメラ境界を拡張できます。

## 操作

- `←` / `A`: 後退
- `→` / `D`: 前進
- `↑` / `↓`: 現在の間合いに複数ある技を切り替え
- `Space`: 現在の間合いの技
- `1`〜`4`: 技を直接選択
- `Shift` / `S`: 接近時にふきとばし（ガッツ消費なし）

画面下のボタンでも操作できます。

スマートフォンを横向きにすると、「ゲームスタート」のタップ時にフルスクリーン表示を要求し、左端に十字キー、右端に「技」と「PUSH」のタッチ操作が現れます。Fullscreen APIが利用できない、またはブラウザに拒否された場合は通常表示のまま続行します。十字キーの左右で移動、上下で現在の間合いの技を切り替えます。十字キーはボタン間を含む領域を重なりのない4方向へ分け、中央の小さなニュートラル領域を除いてタッチを受け付けます。中央下には自分と相手それぞれの4つの間合い、選択中の技名、消費ガッツ、命中率、現在ガッツを表示します。

## バトルルール

- 技は対応する間合いでのみ使用できます。
- 初期・最大ライフはエトキチ500、耐久型のクロボシ625、回避型のステキチ430、最重量級のタツヲ820、術師型のアステール410です。覚醒成功時は自身の最大ライフの25%まで回復します。
- ガッツは時間経過で回復し、値が高いほど命中率が上がります。
- ステージの論理幅は初期版の3倍です。移動速度と技の間合い境界は変わらないため、端までの移動には従来の3倍の時間がかかります。両者が離れるほどキャラクターと背景が最大約50%まで滑らかにズームアウトします。
- ふきとばし距離は初期版の2倍で、相手を一気に押し戻します。フィールド端を越えることはありません。
- 超遠距離技の最大射程を越えると「圏外」になります。圏外では双方とも技を使用できず、技カードは消灯し、命中率欄も「圏外」と表示されます。距離バーには通常4区画とは別に赤い斜線付きの圏外区画を表示します。
- タイトル後のキャラクター選択画面では、自分と相手のキャラクターに加え、3曲からバトルBGMを選べます。同キャラクター同士の対戦も可能です。選択後は戦闘用UIを隠した全画面表示で、選んだ両者の単独ファイティングポーズを順番に映します。最後は各陣営の中央で両者が向かい、その手前に6能力の数値を重ね、背景バーを画面中央から外側へカウントアップします。試合中は相手のガッツ・技・命中率も確認できます。
- 画面下中央に両者の命中率と円形ガッツゲージを左右対称に並べ、技スロット上の連続目盛りへ境界内の正確な間合いを表示します。
- 攻撃・ふきとばし演出中は双方の移動と技入力がロックされ、攻撃側から防御側へ寄るカメラ演出が入ります。
- 技を出した時点で有効な時間制状態は攻防双方について結果確定まで維持され、命中率・回避率・クリティカル率・ライフ/Gダメージへ反映されます。効果時間を超えた場合は「判定中」と表示し、MISSを含む結果確定後に終了します。
- 全キャラクターが敵味方のどちらへ配置しても、それぞれの3フレーム専用歩行サイクルを使います。配置陣営と移動方向に応じて同じ素材を左右反転します。
- 各キャラクターの設定（能力・固有状態・技・画像・アイコン）は自分／相手で共用します。技アニメーションも陣営別の簡略版を持たず、同じ技タイムラインへ攻撃側・対象側・進行方向を渡して左右反転します。
- 技演出中は攻撃側キャラクターを防御側より前面に表示し、ダメージ文字はさらに上の独立エフェクトレイヤーへ表示します。
- 攻撃が外れた側は光の残像を残して一瞬消え、約0.88秒かけて少し後方へ再出現します。回避後の位置は見た目だけではなく実際の間合いにも反映され、フィールド端ではそれ以上後退しません。
- PoCとして「エトキチギャラクシーフラッシュ」は、手元へ収束する脈動オーラ・構え・発射・命中停止・反動・復帰を4.6秒で見せます。命中時は相手を距離35ぶん後方へ飛ばします。演出中も試合時間は進み、防御側だけガッツが回復します。
- ギャラクシーフラッシュの発射座標は発射フレームの手元から動的に算出し、集束球・多層光線・粒子・先端衝撃波を表示します。
- 「ギャラクシーレイ」は専用射撃ポーズ・集光・星弾飛翔・反動・復帰を約2.8秒で見せます。
- 「投げキッス」は遠距離のかしこさ技です。専用横向きポーズ・ハート形成・飛翔・命中時の拡散／MISS時の砕けを約2.8秒で見せ、低威力・高命中・大きなGダメージを与えます。
- 「ダークオービット」は専用低姿勢・多重軌道場・3連弾・反動・復帰を約3.2秒で見せます。
- 「ブラックメテオ」は専用召喚姿勢・上空の渦・隕石形成と落下・地面衝撃波・復帰を約4.2秒で見せます。
- 「エトキチパンチ」は専用横向きポーズ・踏み込み・拳圧・接触・ヒットストップ・復帰を約2.2秒で見せます。
- 「スターリング」は腰の金属リングを身体ごと振り抜き、残像・接触・ヒットストップ・復帰を約2.7秒で見せます。
- 「エトワール・ドライブ」は中距離のかしこさ系自己強化技です。Etoileカードを頭上へ掲げて全身を白金色に発光させ、30秒または次の攻撃結果まで「星纏」になります。次の攻撃はライフダメージ×1.4、命中率+10ポイント、クリティカル率+20ポイントとなり、MISSでも消費されます。
- 「メテオクロー」は専用低姿勢・3本の爪痕・接触・ヒットストップ・復帰を約2.3秒で見せます。
- 「クレセントホーン」は角を倒した突進姿勢・加速線・三日月状の圧力波・接触・ヒットストップ・復帰を約2.9秒で見せます。
- ステキチは近距離「スターダストタッチ」、中距離「ハロースキップ」、遠距離「ステラサーチ」、超遠距離「ディスカバリー・コメット」を使い、超遠距離カードの上下ボタンで回復技「おひるね」へ切り替えられます。間合いと技カードは4枠のままです。5技すべてにステキチ専用のSVGアイコン・キャラクターポーズ・金色と星空色を基調とした専用アニメーション・SEを割り当てています。
- 「おひるね」は消費ガッツ55、基礎成功率65%（使用時ガッツに応じて25〜90%）です。成功するとステキチのライフが最大値まで全回復し、失敗時は回復しません。AIはライフ55%以下になると超遠距離へ移動して使用を狙います。
- ステキチの能力値はライフ430・ちから330・丈夫さ300と低めで、命中620・回避780（特に高い）・かしこさ620に寄せています。ガッツ回復は5.4で、クロボシ2.5・エトキチ2.7のおよそ2倍です。
- タツヲは近距離「タツヲビンタ」、中距離「取り押さえ」、遠距離「腹の底から咆哮」、超遠距離「タツヲプレス」を使います。取り押さえは消費ガッツ42・基礎命中61%と重い代わりに、命中した相手を8秒間「拘束」し、移動速度とガッツ回復速度を3分の1にします。
- タツヲの能力値はライフ820・ちから600・丈夫さ540と高く、命中390・回避250・かしこさ260・ガッツ回復2.3は低めです。ぬいぐるみ由来の巨体と長い腕を活かし、追って耐えて押さえ込む重量級です。
- アステールは近距離技を持たず、中距離「蛇尾薙ぎ」「マイグレーション」、遠距離「魔眼」、超遠距離「デスエナジー」を使います。能力値はライフ410・ちから170・丈夫さ270と低く、命中820・回避560・かしこさ860に特化し、ガッツ回復2.4は少し遅めです。固有状態は「余裕」「本気」です。
- 「マイグレーション」は低命中のかしこさ技で、実際に奪ったライフとガッツを等倍で回復します。「蛇尾薙ぎ」は消費ガッツ12の低コストなちから技です。
- 「魔眼」は通常のライフダメージとGダメージを与えたうえで50%の石化抽選を行います。石化は10秒間続き、移動・攻撃・ふきとばし・ガッツ回復を停止し、受ける技の命中率を100%にします。攻撃を受けても解除されず、技演出中も残り時間が進みます。石化中の姿はPixiJSの色変換・ノイズ・亀裂描画で表現します。
- 各攻撃技は演出中も試合時間が進みます。双方の操作だけをロックし、飛翔体または打撃が届く瞬間に命中・MISS・クリティカルを判定します。演出中に0秒になった場合は、その技の判定と復帰を終えてからTIME UPになります。
- 技ごとにライフダメージとは別の「Gダメージ」を設定できます。
- 技ごとに「ちから／かしこさ依存・威力・命中・Gダメージ・消費ガッツ・クリティカル率」を設定し、クリティカル時はダメージが1.5倍になります。
- 技カードは敵味方とも「SVGアイコン・消費ガッツ・技名」の同一レイアウトで、ちから技は黄色、かしこさ技は緑色に点灯します。
- 同じ間合いに複数の技がある場合、カード外の上下ボタンまたは`↑` / `↓`で選択技を切り替えます。選択位置はカード外のドットで表示します。
- 命中時はキャラクターへライフダメージを大きく重ね、直下へガッツダウン量を約1.4秒表示します。
- クリティカル時は専用SE・衝撃光・放射エフェクト・倍率表示を加え、通常より長く豪華なダメージ演出を表示します。
- MF2を参考にした状態変化「底力」「根性」「本気」「余裕」と、独自状態「嫉妬」「明鏡止水」「覚醒」「ひらめき」「追跡」「快感」「拘束」「石化」を条件・効果・専用演出付きで実装しています。状態は複数同時に有効になります。
- ステキチの「ひらめき」は、相手が3種類の異なる間合いから技を使うと発動します。10秒間、かしこさ技のダメージが1.45倍、命中率が15ポイント、ガッツ回復速度が1.4倍になります。同じ間合いを維持すれば発動を遅らせられます。
- タツヲの「追跡」は、中距離以上で相手が後退する間も1.5秒間前進し続けると発動します。9秒間、移動速度が1.45倍、命中率が12ポイント、ガッツ回復速度が2.5倍になります。
- タツヲの「快感」は、回避を挟まず3回連続で攻撃を受けると発動します。発動時にガッツが30回復し、8秒間はさらに攻撃を受けるたびガッツが15回復します。1試合に1度だけ発動します。
- 「嫉妬」は相手の状態変化ごとに50%で発動します。発動するとガッツが15回復し、8秒間、与えるライフ・Gダメージとクリティカル率が上がる代わりに被ダメージが増えます。抽選失敗後も、次の状態変化で再抽選できます。
- 「余裕」には2系統の発動条件があります。自身の攻撃を5回連続で命中させると確定発動します。また、相手の攻撃を2回連続で回避した時に50%、3回目以降の連続回避では毎回75%で発動抽選します。攻撃をMISSすると命中連続数、相手の技が命中すると回避連続数をリセットします。発動中は技消費と相手の命中率が下がる代わりに被ライフダメージが1.5倍になり、命中を受けると解除されます。
- 「明鏡止水」はガッツ100で1.5秒静止すると発動し、10秒間は回避率99%、移動速度2倍、次の攻撃は命中率99%になります。攻撃を選ぶと終了しますが、その技には命中99%が着弾まで保持されます。
- 状態変化の発動時は対象キャラクターへクローズアップし、発動後は大きな状態名だけをキャラクター頭上中央へ表示します。
- 「覚醒」はライフ0のときに1試合一度だけ25%で抽選され、成功すると最大ライフの25%で復活します。以後は試合終了まで、ライフダメージ×2、Gダメージ×1.5、命中率×1.5、回避率×2、クリティカル率×1.5、ガッツ回復速度×2になります。
- 「根性」は覚醒が発動しなかったKO時に50%で発動し、ライフ1で復活します。覚醒成功後も根性は未使用のまま残り、次のKOで50%抽選されます。
- ライフ0になると約0.65秒かけて一度倒れ、伏したまま1秒待ってから「覚醒」→「根性」の順に復活判定します。どちらも発動しなかった場合だけ、その時点でK.O.が確定します。この間も試合時間は進みますが、双方の操作とAI行動は停止します。
- タイトル画面の「ゲーム開始」から自分／相手のキャラクター選択を経て入場演出へ遷移します。入場中は `Arena Overture` の先頭15.25秒（末尾0.25秒フェード）をループなしで再生し、「対戦開始」を押した場合は途中でも停止します。
- 「FIGHT!」と同時に、キャラクター選択画面で選んだ `Ceremonial Colosseum`、`Ceremonial Colosseum II`、`The Unyielding Titan` のいずれかがループ再生され、復活判定を経てK.O.が確定した時点（またはTIME UP時）で停止します。
- 透過キャラクター素材はWebPへ統一し、クロボシとステキチは `assets/enemies/<敵ID>/`、サラリーマンエトキチ・タツヲ・アステールは `assets/characters/<キャラクターID>/` に格納しています。
- 相手AIは選択キャラクターの全技を使用します。エトキチは間合いごとの攻撃と「エトワール・ドライブ」、ステキチは低ライフ時の「おひるね」も判断します。開幕直後に攻撃せず、判断間隔・待機時間・攻撃後クールダウンが毎回変動します。
- ライフが0になり、倒れてから1秒後の復活判定にも失敗するとK.O.です。
- 60秒経過時は残りライフの割合で勝敗を決めます。
- 決着後は `Arena Crest` の先頭10.95秒（末尾0.25秒フェード）をループなしで再生します。敗者は約3秒かけて縦横比を保ったまま横倒しになり、勝者は既存ポーズから専用の全身勝利画像へ切り替わります。カメラ寄せ・放射光・星粒・勝者名・衝撃SEを含む演出と曲が終了してから、画面を覆わずに「もう一度戦う」ボタンだけが現れます。
